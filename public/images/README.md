# CNM Learning - Asset Organization

This directory contains organized static images for the CNM Learning marketing website.

## Directory Structure & Guidance

- `brand/`: Logos, brand badges, seals, trust markers, and institutional logos.
- `hero/`: Banner visuals, hero product mockups, student hero highlights, and main section graphics.
- `videos/`: Video thumbnails, play button overlays, sample video preview frames, and course teaser imagery.
- `testimonials/`: Student portraits, educator avatars, score cards, and rank holder highlights.
- `features/`: Infographics, feature icons, methodology diagrams, and platform highlights.
- `courses/`: Course banners, subject icons (Physics, Chemistry, Math, Biology), module thumbnails, and batch cards.
- `illustrations/`: Vector art, educational diagrams, decorative background patterns, and custom spot illustrations.
- `general/`: Miscellaneous background textures, fallbacks, and general page assets.
